# 核心操作流程

## 1. 擷取留言

在已登入的 Instagram 分頁開啟 `/p/`、`/reel/` 或 `/tv/` 貼文。點選擴充功能後，在獨立工作分頁按「確認並連接」，再按「開始擷取」。請先確認是正確的貼文。

進度顯示已保存留言、頁數及待抓回覆串；進度條表示目前已發現分頁串的完成比例，新增回覆待辦時可能下降，並非 Instagram 總留言百分比。只有所有留言及回覆分頁走完才會開放正式抽獎。

「暫停擷取」會等正在返回的一頁完成保存，再停止。關閉工作分頁時，最後一次成功提交的頁面與游標仍保留。重新開啟擴充功能，開啟同一 Instagram 貼文後按「繼續擷取」。來源分頁被關閉或切換時也會停止。若原分頁已關閉，可以開啟同一貼文的新分頁。

「取消擷取」保留現有資料供匯出，但不再續抓該活動。重新連接會建立新活動。正在擷取時先暫停，再取消。每個擴充功能來源只允許一個分頁寫入資料／執行擷取；另一分頁會提示返回原分頁。

遇到限流請稍後重試；遇到登入或驗證要求，先回 Instagram 處理。資料格式、游標或回覆數不一致時保留已取得資料、保持未完成。若持續發生，需更新 adapter；不要把部分留言視為全部留言。

## 2. 設定規則

填入字面包含文字、Tag 人數及截止時間。時間固定以台北 UTC+8 解讀，精確到秒，截止當下納入。一般模式可設定 Tag 人數為 0；新朋友模式最低為 1。

選擇「每人一次機會」或「Tag 新朋友增加機會」，上方即時顯示留言数、合格帳號及總籤數。「留言明細」可搜尋、篩選排除原因、點選完整內容；「每人籤數」顯示每個帳號的留言總數及取得的籤數。

新增獎項、指定正整數名額，使用上移按鈕調整抽取順序。預設每個帳號最多得獎一次；可改為同帳號多次得獎，但每張籤只能用一次。規則在切換步驟、切換活動或按「儲存規則，確認抽獎」時保存。輸入中的草稿尚未保存時，直接重整會回到先前設定。

## 3. 確認抽獎

核對貼文、資料完整性、規則、可用帳號與籤數、獎項順序。缺額會明確顯示並阻止抽獎。按下確認後，本機產生一次新的抽獎紀錄。

## 4. 結果與匯出

結果依獎項分組，列出帳號與中獎籤。可選擇歷史紀錄、展開當時規則，或匯出得獎名單與「當時留言及資格」。返回修改規則不會改動已保存的結果；重新抽獎永遠建立新紀錄。

設定頁的「匯出留言及資格」使用目前規則；結果頁的匯出使用該次保存的規則。CSV 含 UTF-8 BOM，支援繁體中文、引號及多行留言，並防護試算表公式注入。

活動資料可在頁尾刪除，需再次確認。刪除會清除該活動的原始留言、資格與籤池及所有抽獎紀錄，不影響其他活動；已下載的 CSV 不會自動刪除。

## 示範活動

「體驗示範活動」提供 240 則本機產生的測試留言、32 個帳號。預設規則可得到 32 張籤；改成新朋友模式可得到 205 張籤。示範資料與匯出檔案皆有明確標示。
